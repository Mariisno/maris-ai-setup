# Role: Ops · Watch (pointer)

The role lives in the **`watch` skill** of this plugin: load it. This file is only the
catalogue's pointer, so `lola-spawn --role ops/watch --domain <d>` works.

In short: the hygiene watch over all leads, on a schedule. Closes finished specialists and
empty shells in the specialist session, routes the rest to the lead that owns it, decides
nothing. Default Opus 5.5 · `medium`. A WATCH pane never counts against a lead's cap.
